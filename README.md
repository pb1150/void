## 项目简介

- 基于 **UE5** 独立开发的类肉鸽第一人称游戏 Demo，核心目标是构建一套可复用的技能、战斗与数值框架。
- 整体框架模块化、封装完善，具备较强扩展性，可支持后续技能、关卡与玩法的快速迭代。


## 使用说明与版权声明

- 本项目主要用于 **个人学习与技术交流**，展示基于 UE5 与 Gameplay Ability System 的战斗与关卡流程实现，并非商业产品。
- 项目灵感来源于《雨中冒险 2》，但本项目与原作及其开发商没有任何官方关联。
- 仓库中仅包含本人编写的 **C++ 源码**，用于展示系统设计与实现思路，不包含关卡、UI 等蓝图资源及第三方美术素材。

## 技术亮点

### 1. 完整流程的 UE5 C++ 项目架构

- 使用 **Unreal Engine 5.4**，以 **C++ 为核心、Blueprint 为扩展** 的混合开发模式：核心系统（道具、技能、战斗、刷怪、数据结构）写在 C++，表现与调试逻辑通过蓝图补充。
- 按功能模块拆分代码结构（AbilitySystem / Game / Character / UI / FunctionLibrary 等），便于维护和扩展。

---

### 2. Gameplay Ability System（GAS）战斗框架与技能系统

- 基于 **GAS** 自定义 `AttributeSet`，管理生命值、移速、护甲、暴击率等战斗属性，为后续平衡和数值扩展打好基础。
- 编写自定义 **GameplayEffect** 与 **MMC（Mod Magnitude Calculation）**，例如格挡几率计算类，用于根据Buff动态计算最终数值。
- 自定义 `FVoidGameplayEffectContext` 继承自 `FGameplayEffectContext`，在命中时额外携带自定义信息。
- 基于 GAS 封装了一套通用技能体系：通过 GameplayTag、DataAsset 与 Ability 类的组合，描述技能类型（普攻、重击、位移、范围技能等）、输入按键以及冷却/消耗等参数。
- 技能系统支持 **冷却、资源消耗、Buff / Debuff、持续伤害/治疗** 等效果，参数由数据驱动，方便策划通过配置调整而无需改代码。
- 能力逻辑主要在 C++ 中实现，触发条件、动画蒙太奇、特效等通过蓝图拼接，实现 **“底层稳定 + 表现灵活”** 的结构。
- 技能与 UI 槽位解耦：技能栏中的每个槽位通过标签或配置绑定到对应 Ability，可在运行时更换技能组合，便于做构筑玩法或技能选择界面。
- 能力系统预留了扩展空间，可以在不改动核心框架的前提下，继续加入例如连击系统、蓄力攻击、特殊状态（无敌、霸体）等高级战斗机制。

---

### 3. 敌人 AI 与战斗系统

- 敌人具备基础感知与行为逻辑：在发现玩家后，使用自定义 AI MoveTo 追击并攻击。
- 支持多种敌人类型（如近战/远程等，可拓展），通过统一的战斗接口/基类复用公共逻辑，便于后续快速增加新怪物。
- 实现 **受击反馈与死亡逻辑**：结合 `FVoidGameplayEffectContext` 中的格挡、暴击、重击等标记，控制不同受击动画、受击飘字与屏幕反馈效果；对已死亡目标的攻击会被过滤，避免重复结算。
- 在敌人死亡时，通过 C++ 函数（ `SpawnDropItems`）生成掉落物，掉落规则可配置，方便日后拓展装备、经验球、随机奖励等系统。

---

### 4. 关卡与怪物生成流程

- 使用自定义的 `AEnemySpawnPoint` 作为敌人生成点，通过标签/权重等方式控制不同区域刷怪类型与数量。
- 在 `GameMode` 中集中管理刷怪逻辑：根据当前存活敌人数、总击杀数等数据来控制刷怪节奏，避免场上怪物过多或过少。
- 当玩家击杀数量达到关卡要求后，由 `GameMode` 生成 **下一关入口**，形成“刷怪 → 解锁出口 → 进入下一关”的完整循环。
- 整套系统以 **数据驱动 + 状态判断** 为核心，后续可以很容易接入不同难度的关卡配置。

---

### 5. 存档系统与运行数据统计

- 通过 `GameInstance` / `SaveGame` 记录关键通关信息，例如：总运行时间、累计击杀数等，为后续战绩结算、排行榜或 Roguelite 统计打基础。
- 设计了记录“**被哪种敌人击杀**”的机制，可以在死亡结算界面展示死亡来源，增强反馈感，同时为后续数据分析提供依据。
- 存档结构预留扩展空间，可进一步记录玩家构筑、选择的天赋、关键事件等，用于实现多周目或永久升级系统。

---

### 6. UI 系统与 DataAsset 驱动的配置

- 使用 UMG + WidgetController 搭建 UI 系统，包括：技能栏、血条、技能选择界面、提示信息等，逻辑与显示分离，方便重构与换皮。
- 通过 `DataAsset` 存储角色、技能、敌人以及数值相关的配置（如冷却时间、消耗、图标、描述等），使大量设计工作可以通过改表完成，而不用频繁改动 C++。
- 支持通过 **Excel 表格配置数据并导入**：数值策划可以在 Excel 中维护角色/技能/敌人配置，再导入为 DataTable/DataAsset 使用，便于批量修改和版本管理。
- UI 交互支持诸如 **道具槽鼠标悬停显示详情、点击触发、按钮音效播放** 等细节，提升可用性与手感。
- 整体 UI 架构围绕“**数据驱动 + 控制器分发事件**”的思路设计，便于将来接入本地化、多语言与不同平台的 UI 方案。
